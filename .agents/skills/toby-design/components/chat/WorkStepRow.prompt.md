Metadata rows that show what Toby did before answering. Deliberately quiet: 10.5px rounded, uppercase, +0.07em tracking, faint body text, accent dot or tool glyph as the marker.

```jsx
<WorkStepRow title="Search mail" body="Found 12 threads since Monday" duration="1.4s" count={3} expandable />
```

Consecutive calls to the same tool aggregate into one row with a `×n` count.
