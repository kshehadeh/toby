The key/value facts at the bottom of a detail pane: 12px labels in row-description color beside 12px values in row-title color, both leading-aligned, 16px apart.

```jsx
<DetailMetadata rows={[{ label: 'ID', value: 'dashboard.calendar.summary', mono: true }, { label: 'Type', value: 'Built-in' }]} />
```

**Native:** `DetailMetadataStack` / `DetailMetadataRow` in `UI/Primitives/DetailInspect.swift`.
