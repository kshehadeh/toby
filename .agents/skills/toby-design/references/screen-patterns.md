# Native screen and window patterns

Use this reference to select composition and ownership. For window/chrome
implementation details, invoke `toby-native-window`.

| Pattern | Canonical source | Rules to preserve |
| --- | --- | --- |
| Main shell | `App/RootView.swift`, `Features/Sidebar/AppSidebar.swift` | `NavigationSplitView` in a standard titled window; no opaque sidebar/toolbar fill; route state/root notifications stay in Root; sidebar is 250pt minimum and owns a stable destination list plus compact persona footer with a server-status indicator. Feature lists belong in the detail workspace via `FeatureWorkspaceSplit` so they sit under the window toolbar separator (same as Chats) instead of flattening into a full-height title-bar column. When Sparkle finds a newer app version, a download button appears in the window toolbar with a TipKit popover pointing at it. |
| Dashboard | `Features/Dashboard/DashboardView.swift` | 24pt inset; 320–460pt waterfall cards/20pt gap in a 940pt area; intrinsic cards capped at 340pt when collapsed; combined recent chats/projects participate as a peer card; Actions in a 120–280pt inspector (156pt default) as wrapping Shortcuts-style colored tiles (flow icon, play glyph, name, 1s hover popover; color from the flow editor). Reorder state remains persisted but has no Home UI entry point. |
| Chat | `Features/Chat/{ChatWorkspaceView,ChatWorkspaceComponents,TranscriptView}.swift` | Switch between empty and active workspace; measured dock height is transcript padding; 18pt bottom gutter; virtualize long transcripts; autoscroll unless the user has scrolled up from the latest content. |
| Integrations | `Features/Configure/{IntegrationsSettingsView,SettingsCatalogView,ConfigureSectionDetailView}.swift` | Settings catalog tab: grouped Form with **Integrations** and **MCP servers** sections, no auto-select. **Add new MCP server** sits at the bottom of the MCP list. A TipKit card below the groups explains the difference. Clicking a row pushes a Form detail (`NavigationStack`) while the sidebar stays on Integrations. Deep links use `selectedNavKey`. |
| Personas | `Features/Configure/{PersonasSettingsView,PersonaEditorFormView}.swift` | Settings catalog tab: grouped Form list of personas, no auto-select. **Add Persona** sits at the bottom of the list. Clicking a row pushes the editor (`NavigationStack`) while the sidebar stays on Personas. The editor uses a segmented **Persona** / **Model** picker (both panes stay mounted). Persona holds icon, name, and instructions; Model holds provider, model, and prompt mode. Deep links use `pendingPersonaSelection`. |
| Settings | `Features/Configure/SettingsWindowView.swift` | Separate preferences window; `NavigationSplitView` sidebar + grouped Form; Personas, Integrations, and AI are catalog tabs that push child detail; deep links via `selectedNavKey`. |
| Recordings | `Features/Recordings/{RecordingsView,RecordingsDetailView,RecordingDetailContent}.swift` | Account for active capture, processing, error, empty, single detail, and multi-selection. Do not auto-select a saved or in-progress recording. Select a newly started recording; keep the last selection when leaving and returning. Detail uses Summary / Transcript tabs (`selectedDetailTab`); selecting a recording resets to Summary. Rename and inspect metadata in `RecordingEditSheet` (EditorSheet Cancel/Save). While summarizing, keep existing summary text (or a Summarizing… placeholder) and apply `intelligenceOutline` to the summary card. |
| Skills | `Features/Skills/{SkillsDetailView,SkillDetailContent,SkillEditorSheet}.swift` | Branch loading → selected inspect detail → unselected placeholder. Do not auto-select. Detail uses About / Instructions tabs (`selectedDetailTab`); selecting a skill resets to About. About is heading + summary + metadata; Instructions is read-only markdown. Create/edit open `SkillEditorSheet`; persist only on Save. Toolbar Edit when selected; `+` opens New Skill. |
| Flows | `Features/Flows/{FlowsDetailView,FlowDetailContent,FlowEditorView}.swift` | Branch loading → selected inspect detail → unselected placeholder. Do not auto-select. Detail uses Details / Recent runs tabs (`selectedDetailTab`); selecting a flow resets to Details. No inspector column — metadata lives on Details. Create/edit present `FlowEditorView` in EditorSheet; window toolbar stays home/detail (never an editor mode). |
| Schedules | `Features/Schedules/{SchedulesDetailView,ScheduleDetailContent,ScheduleEditorSheet}.swift` | Branch loading → selected inspect detail → unselected placeholder. Do not auto-select. Detail uses Details / Prompt tabs (`selectedDetailTab`); selecting a schedule resets to Details. Details holds metadata + recent runs (no card chrome); Prompt holds markdown or a flow summary. Create/edit open `ScheduleEditorSheet` (Details/Prompt form tabs); persist only on Save. Toolbar Edit next to Run / Delete. |
| Projects | `Features/Projects/{ProjectsView,ProjectDetailContent,ProjectEditorSheet}.swift` | Branch loading → selected inspect detail → project chat → unselected placeholder. Do not auto-select. Detail uses Details / Chats tabs (`selectedDetailTab`); selecting a project resets to Details; returning from a project chat opens Chats. Details holds heading, persona metadata, full summary markdown, folder, and file tree (no card chrome); no Chats inspector. Create/edit open `ProjectEditorSheet`; persist only on Save. Toolbar Edit when a project is selected (not during a project chat). |
| Library | `Features/Library/{LibraryView,LibraryInspectorBar}.swift` | Main-window destination after Projects. One-column searchable `FeatureBrowserList` with a Memories-style bottom inspector (`.safeAreaInset`), not `FeatureWorkspaceSplit`. Rows, not a card-grid. Do not auto-select. Empty uses `FeatureBrowserPlaceholder` plus Add. Pending rows use `intelligenceOutline`. Toolbar Add (file importer) and Refresh; inspector Quick Look / Reveal / Delete with confirmation. |
| Feature list | `Features/Sidebar/{FeatureBrowser,FeatureBrowserRow}.swift` plus each workspace sidebar | Shared second-sidebar contract: no automatic first-item selection; empty-area click clears selection; rows use `FeatureBrowserRow` (snapped selection wash, stable glyphs); unselected detail uses `FeatureBrowserPlaceholder` (select copy, plus a create link when the type can be created); stores keep the last selected id across route changes. |
| Command palette | `Features/CommandPalette/{CommandPaletteView,CommandPalettePanelController}.swift` | 560×420 floating nonactivating panel on Liquid Glass; deferred focus; Up/Down/Return/Escape; dismiss on resign/deactivation; save only a visible-screen origin. |

## Ownership and async

- `@Observable @MainActor` stores own loaded data, selected IDs, requests, and
  error/loading state.
- A feature `.task` loads its data. Inspect details do not autosave; entity
  editors persist only from EditorSheet Save.
- Root owns parallel bootstrap/refresh work, global toasts, global sheets and
  alerts, route changes, and cross-feature refreshes.
- Keep stale content during refresh. Do not blank a whole screen for a local
  refresh failure.
