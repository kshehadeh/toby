# Architecture

Toby is a single native macOS app written in Swift. There is no background
server, command-line tool, or plugin system: chat, sources, Home, follow-ups,
flows, recordings, sync, and backups all run inside **Toby.app**.

| Part | What it does |
| ---- | ------------ |
| **TobyAI** | Talks to [OpenRouter](../ai-providers/openrouter): streaming chat with tool calls, structured output, embeddings, model catalog, and sign-in |
| **TobyStore** | The SQLite database (`~/.toby/app/toby.sqlite`) and the one-time import from older versions |
| **TobyCore** | Chat engine and tools, todos and todo sync, memories and the context graph, library, projects, personas, skills, Home, follow-ups, flows, recordings, backups, and the activity log |
| **TobyMail** | Built-in IMAP/SMTP client for [Email](../integrations/email) |
| **Toby.app** | The SwiftUI interface plus macOS access: Calendar, Reminders, Contacts, location, audio capture, speech recognition, notifications, and system controls |

## Background work

While Toby is running (it can stay in the menu bar and start at login), it:

- syncs mail and refreshes **Home**,
- checks for [follow-ups](../followups),
- runs scheduled and event-driven [flows](../flows),
- answers Slack messages when [chat replies](../configuration/inbound-chat) are on,
- syncs todos and writes the daily data backup when [Sync & Backup](../configuration/icloud-sync) is on.

## Privacy

Your data stays in `~/.toby` and your Keychain. Toby sends requests to
OpenRouter for AI, to your mail server and Slack when connected, and to Apple
for macOS services. See [Security](../security).
