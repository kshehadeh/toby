# Sync & Backup

**Settings → Sync & Backup** keeps your todos in sync across your Macs and
saves encrypted backups of everything else.

| Synced continuously | Backed up (not synced) |
| ------------------- | ---------------------- |
| [Todos](../todos) | Chats, memories, projects and their files, flows and run history, recordings, library |

Settings and connected accounts are **not** synced. Set up each Mac's
OpenRouter sign-in and sources on that Mac (or restore a backup file).

## Set up sync

1. Choose where the encrypted vault lives: **iCloud Drive** (default) or a
   folder you pick, such as a shared drive folder.
2. Enter a vault password. Toby stores it in this Mac's Keychain. It cannot be
   recovered: if you lose it, you must start a new vault.
3. On your other Macs, choose the same location and enter the same password to
   join. Toby checks the password before joining.

Everything in the vault is encrypted on your Mac before it is written.

## Daily data backups

Under **Data backups**, turn on daily backups. Once a day while Toby is running,
it writes an encrypted snapshot of this Mac's data (chats, memories, todos,
projects and their files, recordings, and library items) to the vault and
keeps the latest **3** per Mac. Use **Back Up Now** for an immediate snapshot.

Snapshots include audio and transcripts, so they can be large.

To restore, pick a snapshot and choose **Restore**. This **replaces** the data
on this Mac (it does not merge) and relaunches Toby. Settings and accounts are
left alone. Projects are restored inside Toby's data folder.

After a restore, todo sync pauses until you choose **Review and merge…**, so the
restored todos are merged with the vault deliberately.

## Backup files

**File → Backup Toby Data…** saves a password-protected `.tbybak` file with your
data **and** your settings and connected accounts (stored securely in the
file). **File → Restore Toby Data…** restores one on this or another Mac and
relaunches Toby. Backups made by older versions of Toby can be restored too.

## Turning sync off

Disabling sync stops todo sync and daily backups on this Mac and removes the
vault password from the Keychain. You can also delete the vault's copy.
