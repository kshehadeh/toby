# Inbound chat

**Chat replies** let people talk to Toby from Slack: someone @mentions your
Slack app in a channel, or messages it directly, and Toby answers in the same
thread using the persona you choose.

## Turn it on

1. Connect Slack with a **bot token** and an **app-level token** (see
   [Slack → Let Toby reply](../integrations/slack#3-let-toby-reply-in-slack-optional)).
2. Open **Settings → Chat Replies** and turn on **Reply to Slack messages**.
3. Pick the persona Toby replies as (**Reply as**).

Toby connects to Slack over Socket Mode while your Mac is awake and Toby is
running (it can stay in the menu bar and start at login). The sidebar shows
whether replies are connected; if not, the details explain what's missing.

## How it works

- **Chats:** each Slack thread, and each DM, maps to one Toby chat, so
  follow-ups keep context. Replied chats appear in Toby's sidebar.
- **Progress:** while Toby works, it posts a short status line in the thread
  and replaces it with the answer.
- **Questions:** if Toby needs a choice from you, it asks in the thread and
  continues when you answer there.
- **One Mac:** run replies on only one Mac per Slack app; two Macs listening
  with the same app would both answer.
