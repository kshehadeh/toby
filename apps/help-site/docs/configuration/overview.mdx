# Settings overview

Open **Settings** with the gear button in the toolbar or **⌘,**, then pick a
section on the left. Changes save as you make them.

| Section | What it's for | Guide |
| ------- | ------------- | ----- |
| **General** | Data folder, start at login, menu bar icon, shortcuts, Home layout, theme, accent color | [App tour](../toby-app#general) |
| **Account** | Sign in with OpenRouter, credits, and the chat model | [Set up your AI](../getting-started/setup-ai) |
| **Sources** | Connect Mail and Slack | [Connect your apps](../getting-started/configure-and-status) |
| **Personas** | Create and edit personas, and pick each one's model | [Personas](../personas) |
| **Follow-ups** | What Toby watches for and how often | [Follow-ups](../followups) |
| **Recordings** | Summary persona and whether audio is kept | [Recordings](./transcription) |
| **Chat Replies** | Let Toby answer Slack messages | [Inbound chat](./inbound-chat) |
| **Sync & Backup** | Todo sync across Macs, daily data backups, and backup files | [Sync & Backup](./icloud-sync) |
| **Permissions** | Calendar, Reminders, Contacts, microphone, location, and more | [Location](./location) |

## Where your data is stored

By default Toby's data folder is **`~/.toby`**. In **Settings → General → Home
directory** you can choose another folder.

| Path | Contents |
| ---- | -------- |
| `~/.toby/app/toby.sqlite` | Chats, projects, flows and runs, memories, todos, follow-ups, library catalog, and the mail cache |
| `~/.toby/config.json` | Non-secret preferences such as personas, recordings, and chat replies |
| `~/.toby/skills/` | Your skills |
| `~/.toby/projects/` | Project folders |
| `~/.toby/listen/recordings/` | Saved recordings and transcripts |
| `~/.toby/library/` | Files added to the Library |
| `~/.toby/logs/toby.log` | Activity log (also under **Help → Logs**) |

Passwords, tokens, and your OpenRouter key live in the macOS **Keychain**, not
in these files.

When you first open this version of Toby, it imports data from older versions
(`chat.sqlite`, `memory.sqlite`, and credentials) into `app/toby.sqlite` and the
Keychain, then removes the old plugin folders.

For what a backup includes and restore safety, see **[Security](../security)**.
