# Install Toby

**You need:** a Mac with Apple silicon (M1 or later) running macOS 26 or later.

<div className="margin-vert--md">
	<DownloadTobyButton />
</div>

1. Open the downloaded `.dmg` file.
2. Drag **Toby.app** into the **Applications** folder.
3. Open **Toby** from Applications or Spotlight.

The first time you open Toby, macOS may say the app was downloaded from the
internet. Click **Open**. Toby then sets itself up. There's nothing to
install separately.

The button always downloads the latest release.

## What you'll see first

Toby opens on **Home**. Until you've connected an AI provider, Toby can't
answer questions, so start with [Set up your AI](./setup-ai).

Later, macOS will ask for permission when Toby first needs something
protected, such as your calendar, microphone, or contacts. You only need to
allow what you plan to use. You can review all permissions later under
**File → Permissions…**.

## Updates

When a new version is available, a download button appears in the toolbar
with a tip showing the new version number. Click **Upgrade to v…** (or
**Toby → Check for Updates…**) to install it. Your settings and chats are kept.
