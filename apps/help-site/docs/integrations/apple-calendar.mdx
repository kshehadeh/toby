Connect Toby to **Calendar.app** on your Mac to search, create, and update events.


<Callout type="info" title="Platform">


**macOS only.** Calendar tools require Calendar.app on a Mac.


</Callout>

## Setup

Apple Calendar is built into Toby; there is nothing to install or connect.

1. Make sure Calendar.app has the accounts you want (iCloud, Exchange, Google, and so on).
2. The first time Toby needs your calendars, macOS asks for permission. Click **Allow**.
3. To review or change access later, open **Settings → Permissions** (or System
   Settings → Privacy & Security → Calendars).

## Home

Upcoming events from Calendar appear on **Home** for the next few days.

## Example chat prompts

- “What meetings do I have tomorrow between 9am and 5pm?”
- “Create a 30-minute focus block called Deep work tomorrow at 10am on my Work calendar.”

## Tips

- Use exact calendar names from your calendar list when filtering.
- Event UIDs are Calendar.app string identifiers returned by search or create tools.
