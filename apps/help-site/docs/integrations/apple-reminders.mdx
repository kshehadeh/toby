<BrandTitle icon="/img/integrations/apple-reminders.png">Apple Reminders</BrandTitle>
Connect Toby to **Reminders.app** on your Mac to search, create, update, complete, and delete reminders.


<Callout type="info" title="Platform">


**macOS only.** Reminder tools require Reminders.app on a Mac.


</Callout>

## Setup

Apple Reminders is built into Toby; there is nothing to install or connect.

1. Make sure Reminders.app has the accounts you want (iCloud, Exchange, Google, and so on).
2. The first time Toby needs your reminders, macOS asks for permission. Click **Allow**.
3. To review or change access later, open **Settings → Permissions** (or System
   Settings → Privacy & Security → Reminders).

## What you can do in chat

| Capability | Examples |
| ---------- | -------- |
| Lists | List reminder list names and colors |
| Search | Find by text, list, incomplete/completed, due or completion date range |
| Read | Full details for one reminder by id |
| Create | Title, optional notes, list, due date, priority, URL |
| Update | Patch title, notes, list, due date, priority, URL |
| Complete | Mark complete or incomplete |
| Delete | Remove a reminder by id |

Reminder **ids** are Reminders.app string identifiers (not numeric). Prefer ids returned from search or create.

**Priority** uses EventKit values: `0` none, `1` high, `5` medium, `9` low.

Search defaults to **incomplete** reminders unless you ask for completed items or supply completion-date filters.

## Example chat prompts

Name **Apple Reminders** to use this integration. Unqualified todo/task
requests use [Toby Todos](../todos). Clear references to an existing Apple
Reminders item stay there. Toby does not copy tasks between apps.

- “What Apple Reminders do I have due this week?”
- “In Apple Reminders, add Call the dentist next Tuesday at 10am on Personal.”
- “Mark ‘Submit expense report’ in Apple Reminders as done.”
- “List my incomplete Apple Reminders on Work.”

## Tips

- Use **exact list names** from your list when filtering create/search.
- Due and completion filters accept ISO 8601 or simple natural-language dates.
- Apple Reminders is a **Task List Provider**. Its provider preference applies to The Feed and standard-tool Flow steps, not unqualified todo requests.
- Reminders in The Feed have an **Open** button that switches to Reminders.app and shows the list the reminder is in.
