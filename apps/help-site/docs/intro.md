# Welcome to Toby

Toby is a native macOS app that organizes and summarizes work across integrations like Email, Todoist, Slack, Jira, and Apple Calendar. A SwiftUI interface gives you chat, configuration, recordings, schedules, and skills in one place, all backed by a local background service that runs on your Mac.

It combines:

- **Integrations** — connect services and use them from chat
- **Personas** — shape how the assistant prioritizes and responds
- **Skills** — reusable task instructions Toby applies when relevant
- **Memories** — durable context Toby remembers across sessions
- **Projects** — Scoped chats, skills, and memories for a specific context
- **Recordings** — audio recordings with transcriptions and chat integration
- **Schedules** — recurring prompts that run automatically
