# Security

Toby runs on your Mac and keeps your data there. This page explains what is
stored where, how secrets are protected, and what backups contain.

## What Toby protects

| Goal | How |
| ---- | --- |
| Keep secrets out of files | Your OpenRouter key, mail passwords, and Slack tokens are stored in the macOS **Keychain** |
| Keep data on your Mac | Chats, memories, todos, projects, recordings, and library files live in `~/.toby` |
| Protect synced data | The sync vault and backups are encrypted on your Mac with your password (AES-256-GCM, scrypt key derivation) |
| Ask before acting | macOS permissions gate Calendar, Reminders, Contacts, microphone, location, and system controls |

## Where data lives

| Location | Contents |
| -------- | -------- |
| Keychain | OpenRouter key, mail passwords, Slack tokens, sync vault password |
| `~/.toby/app/toby.sqlite` | Chats, projects, flows and runs, memories, todos, follow-ups, library catalog, mail cache |
| `~/.toby/config.json` | Non-secret preferences (personas, recordings, chat replies) |
| `~/.toby/projects/`, `listen/`, `library/`, `skills/` | Project folders, recordings, library files, skills |

## Who Toby talks to

- **OpenRouter**, for AI requests (chat, Home, follow-ups, summaries, web search).
- **Your mail server** and **Slack**, when connected.
- **Open-Meteo**, for weather.
- **GitHub**, to show release notes; **Sparkle**, to check for updates.

Toby has no server of its own and does not collect your data.

## Backup and restore

**File → Backup Toby Data…** writes a `.tbybak` file encrypted with the password
you choose. It contains:

| Included | Not included |
| -------- | ------------ |
| Chats, memories, todos, projects and their files, flows and runs, recordings, library | Theme, menu bar, and home-folder preferences on this Mac |
| `config.json` preferences and your Keychain secrets (OpenRouter, mail, Slack) | |

**File → Restore Toby Data…** checks the password and the file's integrity,
then relaunches Toby and replaces the data on this Mac. Daily data backups in
[Sync & Backup](./configuration/icloud-sync) contain the same data without
settings or secrets.

## Tips

1. Use a strong, unique backup password and store it in your password manager;
   Toby cannot recover it.
2. Never commit `.tbybak` files or your Toby folder to git.
3. Use app passwords for mail when your provider offers them.
4. Revoke Toby's OpenRouter key from your OpenRouter account if you lose a Mac.
