# What Does Toby Do?

Toby is a personal AI assistant that connects to the tools and systems you already use. You chat and configure everything from the native macOS app. Here is what it can do for you.

<FeatureHeading icon="bot" tone="ai" title="Context-aware AI support" />

Toby uses AI together with third-party integrations to give you context-aware assistance in day-to-day life. Connect Email, Todoist, Slack, and other services so Toby can read your email, tasks, calendar, and chat history—and help you act on what matters. See [Integrations](./integrations/overview) for the full list.

<FeatureHeading icon="mic" tone="mic" title="Audio recording and transcription" />

On macOS, Toby can record microphone input and system audio output, then produce transcripts you can review, search, and summarize. Use [Listen mode](./listen) for foreground recording, or ask Toby to summarize a saved transcript in chat.

<FeatureHeading icon="message" tone="chat" title="Chat where you already work" />

Toby integrates with chat apps like Slack so you can talk to your assistant in interfaces that feel familiar. Mention Toby in a channel or DM and it responds in thread, using the same personas, skills, and memories as the native app. See [Slack](./integrations/slack) for setup.

<FeatureHeading icon="app" tone="macos" title="Native macOS app" />

On macOS, the native **Toby.app** is how you use Toby. It gives you a SwiftUI chat and configuration surface. It starts the local background service when needed, then uses that service for sessions, streaming chat turns, and configuration. It also hosts the native API server for permission-gated work such as Calendar and Accessibility. See [Toby.app](./toby-app).

<FeatureHeading icon="apple" tone="macos" title="Deep macOS integration" />

Toby is built for the Mac. It can control system settings and UI elements on your personal computer—Wi‑Fi, battery, audio, shortcuts, and more—so you can ask for changes in plain language instead of hunting through System Settings. See [macOS integration](./integrations/macos).

<FeatureHeading icon="schedule" tone="schedule" title="Scheduled automation" />

You can schedule actions to run at regular intervals. A schedule runs a prompt with a chosen persona on a cron timetable—for example, summarize your email every morning and post the result to Slack or anywhere else Toby can reach. See [Schedules](./schedules).

<FeatureHeading icon="config" tone="config" title="Configuration in the native app" />

Configure your assistant from the [Toby.app](./toby-app) **Settings** and **Integrations** windows. Setup guides walk you through each integration without leaving the app. All settings are stored under `~/.toby/` on your Mac.

<FeatureHeading icon="persona" tone="persona" title="Personas" />

Create different [personas](./personas) to change how your assistant operates: tone, priorities, model choice, and instructions. Switch personas in chat or assign one to a schedule so the same task can be handled differently depending on context.
