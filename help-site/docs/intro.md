# Welcome to Toby

Toby is an AI-assisted CLI for organizing and summarizing work across integrations like Gmail, Todoist, Slack, Azure AD, Apple Mail, and Apple Calendar.

It combines:

- **Integrations** — connect services and use them from chat
- **Personas** — shape how the assistant prioritizes and responds
- **Skills** — reusable task instructions Toby applies when relevant
- **Memories** — durable context Toby remembers across sessions
- **Schedules** — recurring prompts that run automatically
